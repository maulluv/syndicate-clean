# Фото послуг

Файли лежать у `public/services/` — по одному знімку на послугу. Сітка на сторінці «Послуги» та модалка
беруть їх автоматично. Якщо файл прибрати — картка покаже градієнтну плашку
з діамантом бренду, тож нічого не ламається.

Ліцензія Pexels: безкоштовно, зокрема для комерційного використання, без
обовʼязкової згадки автора. Продавати самі фото чи видавати їх за свої не можна.

**Формат:** WebP, 1600 × 1000 px (16:10 — саме таке співвідношення в картці),
кроп по центру. Головний обʼєкт тримай посередині кадру.

## Як замінити на свої

Найкраще — власні знімки з реальних замовлень: клієнт бачить вашу роботу, а не
сток. Достатньо покласти файл із тим самим імʼям — код чіпати не треба.

Підготувати на https://squoosh.app: відкрити фото → **Resize** на ширину 1600 →
формат **WebP**, якість 72–78 → Download. Тримай вагу до ~250 КБ.

Стиль набору, щоб сітка лишалась цілісною: темні теплі кадри, мʼяке бічне
світло, без людей і строкатих кольорів.

Імена файлів налаштовуються в `src/config/site.js` (поле `photo` у масиві `SERVICES`).
