# Фон головного екрана (герой)

| Файл                | Розмір         | Для чого             | Вага   |
| ------------------- | -------------- | -------------------- | ------ |
| `hero-mobile.webp`  | 1080 × 1620 px | телефони (до 768 px) | 134 КБ |
| `hero.webp`         | 1920 × 1080 px | планшети й десктоп   | 137 КБ |

Готові файли лежать у `public/hero/`. Обидва — кропи одного кадру власника
(світла вітальня з бежевим диваном); оригінал 1536 × 1024 збережений поруч
як `source.png`.

Уся ця папка (`design/`) — поза `public/`, тож ні оригінал, ні скрипт, ні цей
README у збірку не потрапляють і на сайті не публікуються. Перевірити:
`npm run build && ls dist/hero` — там мають бути лише два `.webp`.

Кадр **віддзеркалений по горизонталі**: у вихідному фото вікно зліва, а саме
там на десктопі лягає заголовок — світлий текст на засвіченому вікні не
читається. Після дзеркала зліва темніший кут із шафою, а вікно світить справа.
Тексту в кадрі немає, тож дзеркало непомітне.

## Обмеження роздільності

Оригінал 1536 × 1024 — це стеля якості. Вертикальний кроп під телефон бере
смугу 629 × 942 і розтягує її до 1080 × 1620, тобто приблизно в 1.7 раза.
На цьому кадрі це не помітно (він гладкий, без дрібної фактури), але якщо
захочеться ідеальної різкості на телефоні — згенеруй окремий **вертикальний**
варіант близько 1024 × 1536, тоді розтягування не буде взагалі.

## Як перегенерувати

Скрипт, яким зроблені обидва файли (кроп + дзеркало + WebP), лежить поруч:
`generate.py`. Він читає `design/hero/source.png` і кладе результат
у `public/hero/`. Щоб узяти інший кадр — просто заміни `source.png`.

```bash
python3 design/hero/generate.py
```

Потрібен Pillow (`python3 -m pip install pillow`).

## Як замінити вручну

Клади файли з тими самими іменами — код чіпати не треба. Якщо файлів немає,
герой сам показує градієнтний фон і нічого не ламається.

Який кадр шукати: вітальня з мʼякими меблями, спокійне світло, вільний простір
**зліва** (там заголовок «Досконала ЧИСТОТА»).

Імена файлів і брейкпоінт задані в `src/pages/Home/Home.jsx` (компонент `HeroBackground`).

## Затемнення

Фото світле, а текст кремово-золотий, тож затемнення підібране під нього і
перевірене на контраст (`src/pages/Home/Home.module.css`, клас `.overlay`):

- **від 901 px** — затемнення зліва направо: текст ліворуч, вікно праворуч лишається світлим;
- **до 900 px** — затемнення знизу вгору, текст притиснутий до низу, згори видно кімнату;
- зверху окрема смуга, щоб лого й меню не губились на світлій стіні.

Якщо поставиш темніше фото — затемнення можна послабити. Контраст усього
тексту зараз від 4.4:1 (норма WCAG AA — 4.5:1 для дрібного, 3:1 для великого).
