# Картинка прев'ю посилання (Open Graph)

Файл: `public/og-cover.jpg` — те, що видно, коли посилання на сайт кидають
у Telegram, Facebook, Viber, WhatsApp чи X.

## Вимоги

| Параметр | Значення |
|---|---|
| Розмір | **1200 × 630** px (співвідношення 1.91:1) |
| Формат | JPG або PNG |
| Вага | до 300 КБ, бажано менше — інакше месенджери довго тягнуть прев'ю |

Розмір саме такий, бо він зашитий у теги `og:image:width` / `og:image:height`
(див. `scripts/generate-seo.mjs`). Якщо міняєш пропорції — онови й їх.

## Як замінити

Просто поклади новий файл на місце `public/og-cover.jpg` і зроби `npm run build`.
Шлях правити не треба: він заданий один раз у `src/config/site.js` (`OG_IMAGE`).

## Що має бути на картинці

Її дивляться в стрічці розміром зі сірникову коробку, тож:

- великий напис — назва бренду і одна фраза про суть;
- НЕ дрібний текст: абзаци й довгі речення не читаються;
- важливе тримати подалі від країв — деякі месенджери обрізають краї;
- телефон варто лишити: у прев'ю його видно без переходу на сайт.

## Після заміни

Месенджери кешують прев'ю надовго. Щоб побачити нову картинку одразу:

- Facebook / Messenger — [Sharing Debugger](https://developers.facebook.com/tools/debug/), кнопка «Scrape Again»;
- Telegram — напиши боту [@WebpageBot](https://t.me/WebpageBot) посилання на сайт;
- решта — зазвичай оновлюється саме протягом доби.
