# SYNDICATE CLEAN — сайт хімчистки меблів

Сайт-портфоліо для бізнесу з чищення меблів (Київ та область). Vite + React + React Router, CSS Modules.

## Запуск

```bash
npm install
npm run dev
```

Далі відкрий адресу, яку покаже термінал (зазвичай http://localhost:5173).

Збірка на прод:

```bash
npm run build
npm run preview
```

## Структура

```
src/
├── config/
│   └── site.js        # ⭐ УСІ ДАНІ: соцмережі, контакти, послуги, хімія, меню
├── components/        # реюзабельні компоненти
│   ├── Button/        # єдина кнопка (variant: primary | outline | ghost; size: sm | md | lg)
│   ├── Logo/          # SVG-логотип (легко замінити назву/знак)
│   ├── Container/     # обгортка ширини контенту
│   ├── Header/        # шапка + навігація + мобільне меню
│   ├── Footer/        # футер
│   ├── Modal/         # універсальне модальне вікно (Esc / клік на фон)
│   ├── OrderModal/    # модалка вибору месенджера («Замовити»)
│   ├── ServiceCard/   # картка послуги (hover-play відео, клік → ServiceModal)
│   ├── ServiceModal/  # модалка послуги (автозапуск відео + опис + «Замовити»)
│   ├── ChemistryCard/ # картка засобу (hover-анімація, відкриває модалку)
│   ├── ChemBottle/    # SVG-флакон (тимчасова заглушка замість фото)
│   ├── ReviewCard/    # картка відгуку «до | після» (чорна риска посередині)
│   ├── ReviewModal/   # модалка відгуку зі слайдером «До → Після»
│   ├── SofaShot/      # SVG-диван «до/після» (тимчасова заглушка замість фото)
│   └── icons/         # усі SVG-іконки (Instagram, Telegram, Facebook…)
├── context/
│   └── OrderModalContext.jsx  # глобальна модалка замовлення (useOrderModal)
├── pages/             # кожна сторінка в окремій папці
│   ├── Home/          # Головна (герой + місце під відео)
│   ├── Services/      # Послуги (картки з відео + модалка)
│   ├── Chemistry/     # Хімія (картки + модалка з описом)
│   ├── Reviews/       # Відгуки (картки «до/після» + слайдер у модалці)
│   └── Contacts/      # Контакти (без форм — вибір месенджера)
├── layouts/
│   └── MainLayout/    # Header + контент + Footer
└── styles/
    ├── variables.css  # кольори, шрифти, відступи (усі токени тут)
    └── global.css     # глобальний reset + базові стилі
```

## Як що змінити

Майже все — у **`src/config/site.js`**:

- **Бренд** (`BRAND`) — назва, підпис (tagline), слоган. Підхоплюються логотипом, футером і `<title>`.
- **Соцмережі власника** (`SOCIAL`) — посилання на Instagram / Telegram / Facebook. Підхоплюються модалкою «Замовити», футером і сторінкою Контакти.
- **Контакти** (`CONTACTS`) — телефон, пошта, місто, графік.
- **Послуги** (`SERVICES`) — назва, опис, ціна, відео (наочні картки). Відео зараз лежать у `public/videos/demo-*.mp4` (тимчасові заглушки) — поклади свої ролики туди та онови шлях.
- **Прайс-лист** (`PRICING`) — категорії (`Дивани`, `Меблі`, `Матраци`, `Додатково`) з позиціями та цінами. Рендериться на сторінці «Послуги».
- **Переваги** (`FEATURES`) — блок значків довіри під прайсом.
- **Хімія** (`CHEMISTRY`) — назва, короткий підпис, колір флакона, опис.
- **Відгуки** (`REVIEWS`) — автор, роль, текст, `tone` (колір ілюстрації). Фото «до/після» поки замінені SVG-диваном; для реальних фото — заміни `<SofaShot>` на `<img>` у `ReviewCard`/`ReviewModal`.
- **Меню** (`NAV_LINKS`) — пункти навігації.

Інше:

- **Назва бренду / логотип** — `src/components/Logo/Logo.jsx` (проп `name`, `tagline`; сам знак — у `LogoMark`).
- **Кольори / шрифти** — `src/styles/variables.css`.
- **Відео на головній** — поклади ролик у `public/hero.mp4` і розкоментуй `<video>` у `src/pages/Home/Home.jsx`.
- **Фото замість SVG-флаконів** — у `src/components/ChemistryCard/ChemistryCard.jsx` заміни `<ChemBottle>` на `<img>`.
- **Додати сторінку** — створи папку в `src/pages/`, додай маршрут у `src/App.jsx` і пункт у `NAV_LINKS`.

> ⚠️ Відео в `public/videos/` — cc0-заглушки (Mozilla / W3Schools) лише для прикладу. Заміни на реальні ролики процесу чищення.
