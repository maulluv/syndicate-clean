# SYNDICATE CLEAN — сайт хімчистки меблів

Сайт-портфоліо для бізнесу з чищення меблів (Київ та область). Vite + React + React Router, CSS Modules.

## Запуск

```bash
npm install
npm run dev
```

Далі відкрий адресу, яку покаже термінал (зазвичай http://localhost:5173).

Збірка на прод:

```bash
npm run build
npm run preview
```

## Як що змінити

Майже все — у **`src/config/site.js`**:

- **Бренд** (`BRAND`) — назва, підпис (tagline), слоган. Підхоплюються логотипом, футером і `<title>`.
- **Соцмережі та месенджери** (`SOCIAL`) — посилання на Telegram / Facebook / Instagram. Viber і WhatsApp окремо вписувати не треба: вони будуються з `CONTACTS.phone` і оновлюються самі, якщо змінити номер. Порожній рядок = кнопка показується, але неактивна, з підписом «Скоро» (зараз так з Instagram — впиши URL, і вона заживе).
- **Порядок і підписи каналів** — `src/config/channels.js`. Один список на весь сайт: футер, модалка «Замовити» і сторінка «Контакти» беруть канали звідти, тож новий месенджер додається в одному місці.
- **Контакти** (`CONTACTS`) — телефон, пошта, місто, графік.
- **Послуги** (`SERVICES`) — назва, опис, ціна, відео (наочні картки). Відео зараз лежать у `public/videos/demo-*.mp4` (тимчасові заглушки) — поклади свої ролики туди та онови шлях.
- **Прайс-лист** (`PRICING`) — категорії (`Дивани`, `Меблі`, `Матраци`, `Додатково`) з позиціями та цінами. Рендериться на сторінці «Послуги».
- **Переваги** (`FEATURES`) — блок значків довіри під прайсом.
- **Хімія** (`CHEMISTRY`) — назва, короткий підпис, колір флакона, опис.
- **Відгуки** (`REVIEWS`) — автор, роль, текст, `tone` (колір ілюстрації). Фото «до/після» поки замінені SVG-диваном; для реальних фото — заміни `<SofaShot>` на `<img>` у `ReviewCard`/`ReviewModal`.
- **Меню** (`NAV_LINKS`) — пункти навігації.

Інше:

- **Назва бренду / логотип** — `src/components/Logo/Logo.jsx` (проп `name`, `tagline`; сам знак — у `LogoMark`).
- **Кольори / шрифти** — `src/styles/variables.css`.
- **Відео на головній** — поклади ролик у `public/hero.mp4` і розкоментуй `<video>` у `src/pages/Home/Home.jsx`.
- **Фото замість SVG-флаконів** — у `src/components/ChemistryCard/ChemistryCard.jsx` заміни `<ChemBottle>` на `<img>`.
- **Додати сторінку** — створи папку в `src/pages/`, додай маршрут у `src/App.jsx`, пункт у `NAV_LINKS` **і обовʼязково запис у `SEO`** (див. розділ «SEO» нижче). Якщо забути SEO — збірка попередить у консолі.

> ⚠️ Відео в `public/videos/` — cc0-заглушки (Mozilla / W3Schools) лише для прикладу. Заміни на реальні ролики процесу чищення.

## SEO і прев'ю посилань

### Як це влаштовано

Сайт — SPA: сервер віддає один HTML, а сторінки малює React у браузері.
Проблема в тому, що робот Google і краулери Telegram/Facebook **не виконують
JavaScript** — вони читають лише той HTML, що прийшов з сервера. Тому мета-теги,
проставлені React-ом, вони не бачать.

Розвʼязано так: `npm run build` після збірки запускає `scripts/generate-seo.mjs`,
і той кладе **окремий готовий HTML для кожної сторінки**:

```
dist/index.html            → головна
dist/poslugy/index.html    → Послуги
dist/himiya/index.html     → Хімія
dist/kontakty/index.html   → Контакти
dist/404.html              → сторінка не знайдена (noindex)
dist/sitemap.xml
dist/robots.txt
```

У кожному — свій `<title>`, опис, `canonical`, картинка прев'ю і розмітка
`LocalBusiness` (з неї Google бере телефон, графік і місто для видачі).
Для живого відвідувача те саме робить `src/hooks/usePageMeta.js` при переходах
між сторінками — тексти обидва беруть з одного місця, тож розʼїхатись не можуть.

### Що і де правити

| Що | Де |
|---|---|
| Заголовок і опис сторінки | `SEO` у `src/config/site.js` |
| Домен сайту | `SITE_URL` у `src/config/site.js` |
| Телефон, графік, місто у видачі Google | `CONTACTS` у `src/config/site.js` |
| Картинка прев'ю посилання | `public/og-cover.jpg` (див. `design/og/README.md`) |
| Лічильник Google Analytics | `ANALYTICS.ga4` у `src/config/site.js` |

Файли `sitemap.xml`, `robots.txt` і мета-теги руками не пишуться — вони
генеруються зі списку вище під час збірки.

### Аналітика

За замовчуванням вимкнена: `ANALYTICS.ga4` порожній, і на сайт не потрапляє
жодного стороннього скрипта. Щоб увімкнути — встав Measurement ID з Google
Analytics (виду `G-XXXXXXXXXX`) і перезбери сайт. Переходи між сторінками
рахуються окремо, бо в SPA вкладка не перезавантажується.

У режимі розробки лічильника немає ніколи — статистику не засмічують
власні відкриття сайту.

### Перевірити перед запуском

```bash
npm run build
npx wrangler dev
```

Далі відкрий адреси й переконайся, що заголовки різні, а неіснуюча сторінка
віддає 404:

```bash
for p in / /poslugy /himiya /kontakty /nema-takoyi; do
  curl -s -o /tmp/p -w "$p → %{http_code}  " "http://localhost:8787$p"
  grep -o '<title>[^<]*' /tmp/p | sed 's/<title>//'
done
```

Готове прев'ю посилання можна перевірити на
[Facebook Sharing Debugger](https://developers.facebook.com/tools/debug/)
(працює лише з опублікованим сайтом, не з localhost).

### Після першого деплою

1. Додай сайт у [Google Search Console](https://search.google.com/search-console)
   і подай `sitemap.xml` — так сторінки потраплять в індекс за дні, а не тижні.
2. Заведи картку в Google Business Profile: для локальної послуги вона дає
   більше звернень, ніж сам сайт.

## Форма заявки

Заявка з сайту приходить у Telegram-групу. Шлях такий:

```
форма на сайті → POST /api/order → worker/order.js → Telegram Bot API → група
```

Обробка на сервері, а не в браузері, з однієї причини: щоб надіслати
повідомлення, потрібен токен бота, а все покладене в код сайту видно кожному
відвідувачу через «переглянути код». Токен лежить у сховищі Cloudflare —
браузер клієнта його не бачить ніколи.

### Налаштування

Два значення, обидва в сховищі Cloudflare (у git не потрапляють):

| Секрет | Що це |
|---|---|
| `TELEGRAM_BOT_TOKEN` | токен від [@BotFather](https://t.me/BotFather) |
| `TELEGRAM_CHAT_ID` | куди слати заявки; для групи це **відʼємне** число |

Записати або змінити:

```bash
npx wrangler secret put TELEGRAM_CHAT_ID
```

Деплой після цього не потрібен — секрет підхоплюється одразу.

### Як дізнатись chat_id

1. Додати бота в групу
2. Написати в групі будь-що
3. Відкрити `https://api.telegram.org/bot<ТОКЕН>/getUpdates`
4. Взяти `"chat":{"id":-100…` із записом `"type":"supergroup"`

⚠️ **Головна пастка.** Telegram підвищує звичайну групу до супергрупи при
зміні складу чи налаштувань, і `chat_id` при цьому **змінюється**. У відповіді
це видно як `migrate_to_chat_id` — правильний завжди новий номер. Якщо заявки
раптом перестали приходити, причина майже напевно саме ця: берете новий ID і
оновлюєте секрет.

### Захист від спаму

У формі є приховане поле-пастка (`website`). Людина його не бачить, а
автоматичний заповнювач форм — заповнює. Якщо воно не порожнє, сервер віддає
`ok: true`, але в Telegram нічого не шле: спамер не має зрозуміти, що його
відсіяли, інакше просто підбере обхід.

Плюс перевірки на сервері: імʼя 2–80 символів, у телефоні щонайменше 9 цифр,
коментар до 1000 символів, послуга приймається лише зі списку `SERVICES`.

### Передача власнику

Оскільки заявки йдуть у групу, а не конкретній людині, передача — це зміна
складу групи, без коду й деплою:

1. Додати власника в групу, зробити адміном
2. Передати бота: [@BotFather](https://t.me/BotFather) → `/mybots` → бот → **Transfer Ownership**
3. Вийти з групи

Для кроку 2 Telegram вимагає ввімкнену двоетапну автентифікацію **щонайменше
7 днів** — вмикати треба заздалегідь, інакше передача не дасться.
